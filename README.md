# Homebrew Gear CI

[![Release](https://img.shields.io/github/v/release/wxyy-org/gear-ci-release)](https://github.com/wxyy-org/gear-ci-release/releases)

Gear CI 的 Homebrew Tap 仓库。此仓库由 [gear-ci](https://github.com/wxyy-org/gear-ci) 主仓自动同步，请勿手动修改。

## 安装

```bash
brew tap wxyy-org/gear-ci
brew install gear-ci
```

## 更新

```bash
brew update
brew upgrade gear-ci
```

## 使用

```bash
gear-ci --version
```
